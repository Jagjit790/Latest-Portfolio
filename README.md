# Jagjit Builds

Create a highly creative, premium personal portfolio website for a B.Tech Computer Science student and aspiring Full Stack Developer.

The website must feel human-designed, distinctive, memorable, and thoughtfully crafted — NOT like an AI-generated portfolio template.

CORE DESIGN DIRECTION

Do NOT copy, reproduce, or closely imitate any existing portfolio website, template, Dribbble design, or popular developer portfolio.

Instead, study the general strengths found across excellent modern portfolios — such as:

strong visual hierarchy

excellent typography

smooth navigation

storytelling

interactive project presentation

tasteful animations

clear calls to action

responsive layouts

meaningful micro-interactions

strong use of whitespace

personality

Then combine these principles into a completely original visual identity and layout.

The final result should look like a talented human designer/developer personally designed it over several iterations.

Avoid:

generic AI portfolio layouts

excessive glassmorphism

huge meaningless gradients

overused purple/blue AI aesthetics

generic “Hi, I'm X, I'm a developer” hero sections

excessive rounded cards

template-like sections stacked one after another

unnecessary animations everywhere

stock-looking illustrations

fake testimonials

meaningless statistics

excessive text

visually noisy interfaces

The design should be creative without sacrificing usability.

Name:
Jagjit Singh Khalsa

curious

focused on turning ideas into working products

Do NOT portray me as an expert or senior developer.

The portfolio should honestly communicate that I am a student who is actively building, experimenting, learning, and improving.

Use:

restrained but memorable accent colors

subtle texture/details where appropriate

The design should feel similar to the quality level of a carefully designed startup/product website rather than a traditional resume website.

Use a consistent design system throughout.

Typography should feel modern and premium but remain highly readable.

The UI should feel polished on:

desktop

laptop

tablet

mobile

The hero should communicate:

Mention the Full Stack Development minor naturally.

Show my development journey visually rather than presenting a huge wall of text.

Potential structure:

Keep the content authentic.

"A developer designed his own digital space."

The visitor should understand within seconds:

Ensure:

responsive layout

mobile-friendly navigation

RESPONSIVE DESIGN

Do not simply shrink the desktop version.

Design intentionally for mobile.

On mobile:

simplify complex compositions

maintain visual hierarchy

make buttons touch-friendly

ensure project previews remain attractive

use a clean mobile navigation

avoid horizontal overflow

preserve animations only where they perform well

TECHNICAL DIRECTION

Use a modern production-quality frontend architecture.

Prefer:
React / Next.js
Tailwind CSS
Framer Motion or an equivalent animation library
Lucide icons or another clean icon system

Use reusable components.

Maintain:

clean component structure

consistent spacing

reusable UI primitives

semantic HTML

maintainable CSS

responsive design

Do not create unnecessary dependencies.

Optimize for performance.

CONTENT RULES

Never invent:

job experience

companies worked for

awards

client names

revenue

user numbers

fake testimonials

fake statistics

fake certifications

If information is unavailable, create a clean placeholder that can easily be replaced later.

The portfolio should represent a real student/developer honestly.

FINAL CREATIVE DIRECTION

Think of this website as a combination of:

Developer portfolio
+
Personal digital identity
+
Interactive project showcase
+
Mini product experience

It should NOT feel like a resume placed inside a website.

It should feel like a digital representation of Jagjit's journey as a builder.

Before generating the UI, internally explore several different layout possibilities and combine the strongest ideas into ONE original design.

Do not copy an existing portfolio.

Do not follow a recognizable portfolio template.

Create something that could become a recognizable personal brand.

The final result should make a recruiter think:

"This person actually builds things."

And make another developer think:

"This portfolio has its own identity."

Prioritize originality, usability, storytelling, authenticity, and visual craftsmanship.
